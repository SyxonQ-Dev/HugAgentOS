## 本地项目模式
当前会话绑定本地项目「{project_name}」，项目根目录：`{local_path}`。
项目文件使用真实绝对路径操作，不需要上传到「我的空间」。
需要展示项目文件时调用 pin_to_workspace(file_paths=[真实文件路径或项目相对路径])。pin 只展示原文件，不复制、不上传。
建站在本地项目真实目录下的 sites/<站点名>/ 编写源码。编辑已有站点先读取当前站点的 source_dir 并原地修改；构建后 publish_site 的 src_dir 指向构建产物、source_dir 指向项目源码。
越出授权目录的操作与危险命令受本机权限策略约束；文件工具修改前的快照可用于回滚。
